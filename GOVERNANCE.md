# Governance

Sinetti is currently maintained by the repository collaborators who hold
GitHub maintain or write access.

Changes land through pull requests. At least one maintainer must approve a
change before merge; contract, security-policy, or release changes must include
the evidence and tests needed to support their claims. Maintainers may merge an
urgent security fix before full public discussion and document the decision
after coordinated disclosure permits it.

Project decisions should be recorded in this repository's issues, discussions,
or pull requests. Maintainers appoint or remove maintainers by consensus based
on sustained contribution, sound review, and responsible handling of security
information.
