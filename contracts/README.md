# Contracts

This directory contains the unaudited V04 escrow, its arbitrator interface, the
optional `ConsoleArbitrator` reference, and mocks required by local examples and
tests. Participant and arbitrator allowlists are independently optional;
generated artifacts and deployment output do not belong in the repository. No
supported deployment exists. See
[DESIGN-NOTES.md](../DESIGN-NOTES.md) and the [roadmap](../ROADMAP.md).
