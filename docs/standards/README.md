# Standards

ERC-8004 identity and A2A agent-discovery integrations are deferred and not
implemented in this repository. Any future interoperability claim must pin exact
supported versions and include a tested integration flow.

Reputation computation, scoring, and aggregation are deferred from the initial
release. This repository makes no commitment about a future architecture until
that scope is separately designed and supported by code and evidence. See
[DESIGN-NOTES.md](../../DESIGN-NOTES.md).
